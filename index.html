Официальный старт с Codex ↗
2

Создайте отдельную папку «Мой первый сайт»

Скачайте макет на предыдущем шаге и положите index.html в эту папку. Откройте эту папку как проект в Codex. Так ИИ будет работать с вашим сайтом, а не с другими документами.

Не видите, как открыть папку? Напишите в чате Codex: «Я новичок. Помоги открыть локальную папку с index.html как проект. Давай по одному действию с учётом моей системы».

3

Передайте задание и дождитесь результата

Скопируйте текст ниже в новый чат вашего проекта. Codex должен изменить сам файл. Когда работа завершится, откройте index.html двойным щелчком в браузере. После новой правки обновите страницу.

Codex — это диалог. Не получилось с первого раза? Напишите об этом в том же чате проекта. Например: «На телефоне заголовок обрезается. Исправь это в index.html и объясни простыми словами, как проверить результат». Можно задавать уточняющие вопросы и просить новые правки.

Не получается скопировать? Нажмите в поле с заданием и выделите текст вручную. Или скачайте задание файлом и откройте его.
Нужны ли навыки с GitHub?

Для первого сайта — нет. Навык (skill) — это дополнительная инструкция для ИИ: например, о дизайне или проверке интерфейса. Хороший бриф и конкретное задание важнее установки набора дополнений.

Когда появится опыт, посмотрите официальный каталог примеров плагинов и навыков. Старый репозиторий openai/skills помечен как устаревший и отсылает в каталог плагинов. Не устанавливайте всё подряд и не передавайте неизвестным дополнениям ключи.

Если открыт только Codex в браузере

Веб-режим и локальный проект — разные маршруты. Веб-режим может потребовать настройки репозитория GitHub и рабочего окружения. Чтобы не добавлять эти шаги в первый урок, основной маршрут здесь — приложение с локальной папкой. Не вставляйте задание в случайный чат, ожидая, что он сам изменит файл на компьютере.

Маршрут без команд

Cloudflare Pages

Есть бесплатный план с лимитами. Для нашего одностраничного сайта подходит ручная загрузка папки — без настройки сборки.

  1. Войдите в свой аккаунт Cloudflare и откройте раздел Workers & Pages.
  2. Выберите создание проекта Pages и ручную загрузку — Direct Upload / Drag and drop.
  3. Укажите имя проекта и перетащите папку, в которой лежит готовый index.html.
  4. Нажмите публикацию (Deploy site). Откройте выданную ссылку вида имя.pages.dev.

В ручной загрузке: до 1000 файлов, до 25 MiB на файл. Для одного HTML этого достаточно. Названия пунктов интерфейса могут меняться.

Инструкция с актуальными шагами ↗

Vercel

Есть бесплатный план Hobby с ограничениями. Способ публикации и соответствие вашего проекта условиям плана проверьте перед загрузкой. Здесь мы его не настраиваем.

Для автоматических обновлений можно подключить репозиторий GitHub с сайтом. Это дополнительный шаг, а не условие первого результата.

Свой хостинг — тоже подходит

Если он поддерживает обычные HTML-сайты, загрузите файлы в папку сайта по инструкции провайдера. Домен покупается отдельно, если нужен свой адрес.

А Тильда? Это отдельный конструктор. Загрузку готового HTML-сайта как универсальный маршрут здесь не используем. В официальной инструкции описан обратный процесс: экспорт сайта из Тильды на свой хостинг на плане Business. Для нашего файла проще выбрать обычный статический хостинг.
А заявки, оплата и личный кабинет?

В этом практикуме кнопка ведёт на вашу почту или страницу связи. Форма, которая сохраняет заявки, оплата и авторизация требуют отдельной настройки. Не добавляйте визуальную форму с ложным сообщением «Отправлено». Перед реальным сбором персональных данных продумайте согласие, политику и место хранения.
