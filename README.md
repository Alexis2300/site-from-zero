# Сайт с нуля — Александр Гасс

Бесплатный интерактивный практикум: от идеи до первого одностраничного сайта с помощью Codex.

## Открыть приложение

https://Alexis2300.github.io/site-from-zero/

## Что внутри

- Пять шагов: подготовка, бриф и макет, задание для Codex, проверка, публикация.
- Живой макет, три примера, варианты оформления и скачивание HTML-сайта.
- Персональное задание для отдельного Codex и подсказки для новичков.
- Крупные шрифты, мобильная версия и синяя неоновая тема.

## Как работает

Один автономный `index.html`: HTML, CSS и JavaScript, без сборки и сторонних библиотек. Макет создаётся встроенным шаблоном; ИИ-генерация в приложение не встроена. Доработка с ИИ выполняется пользователем отдельно в его Codex.

Бриф и прогресс хранятся в localStorage браузера; приложение не передаёт их на сервер. Аккаунты, ключи и подписки не включены. Хостинг GitHub Pages может вести технические журналы посещений по правилам GitHub.

## Локальный запуск

Скачайте `index.html` и откройте его в браузере на компьютере.

## Публикация

GitHub Pages: корень основной ветки. Файл `.nojekyll` отключает обработку Jekyll.
